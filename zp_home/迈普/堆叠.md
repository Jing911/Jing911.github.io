> <p style="font-size:30px">堆叠(VST)</p>

注意事项：先完成主设备配置，重启主设备后再配置备设备

- <b><p style="font-size:17px">1. 配置命令</p>
主设备配置：
|命令|注释|
|:-:|:-:|
enable|进入特权模式</p>特权模式下通过show int sw查看端口，配置模式下在前面加do，同思科|
configure terminal|进入全局配置模式|
switch virtual member 1|配置成员编号为1</p>输入yes|
 domain 110|配置域编号为110|
 priority 150|配置优先级为150|
 exit|退出|
vsl-channel 1|创建虚拟交换链路接口-1|
 exit|退出|
interface fortygigabitethernet0/49|进入堆叠用物理接口|
 vsl-channel 1 mode on|划入虚拟交换链路-1|
description VST|注释|
 exit|退出|
interface fortygigabitethernet0/50|进入堆叠用物理接口|
 vsl-channel 1 mode on|划入虚拟交换链路-1|
description VST|注释|
 exit|退出|
 end|返回用户视图|
write|保存配置|
switch mode virtual|配置主设备运行模式为堆叠模式</p>切换运行模式涉及设备重启，需要输YES确认|

查看堆叠状态：</p>

|命令|注释|
|:-:|:-:|
show switch virtual |查看堆叠状态|
show switch vsl-channel |查看堆叠通道状态|
