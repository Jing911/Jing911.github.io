
> <p style="font-size:30px">链路聚合</p>

<span style="text-indent:2em;">

- <b><p style="font-size:17px">一、介绍</p></b>
链路聚合，是将多条物理链路捆绑在一起形成一条逻辑链路，可以实现增加链路带宽，实现链路冗余备份，流量负载均衡，有效的提高链路的可靠性。</p>

- <b><p style="font-size:17px">二、术语</p></b>
 1、聚合成员术语</p>

1.1 聚合组 -- 多个以太网接口捆绑在一起后，会形成一个聚合组，一个聚合组对应一个聚合接口</p>

1.2 成员端口 -- 被划分进聚合组、捆绑在一起的物理端口</p>

1.3 选中/非选中状态 -- 表示成员端口的状态，处于选中状态时，会进行流量的转发，处于非选中状态时，不会转发流量</p>

1.4 参考端口 -- 从成员端口中选举出来的端口，为本地有效，具有抢占性。根据参考端口参数来决定成员端口的状态</p>

1.5 成员端口的状态

	聚合组内的成员端口具有以下三种状态：
	选中（Selected）状态：此状态下的成员端口可以参与数据的转发，处于此状态的成员端口称为“选中端口”。
	非选中（Unselected）状态：此状态下的成员端口不能参与数据的转发，处于此状态的成员端口称为“非选中端口”。
	独立（Individual）状态：此状态下的成员端口可以作为普通物理口参与数据的转发。当聚合接口配置为聚合边缘接口，其成员端口未收到对端端口发送的LACP（Link Aggregation Control Protocol，链路聚合控制协议）报文时，处于该状态。

 2、聚合条件术语</p>

2.1 操作Key -- 根据成员端口的信息（端口速率、双工模式等）的组合自动计算生成的数值，代表成员端口的聚合能力</p>

2.2 属性类配置 -- 包括端口隔离配置（端口是否加入隔离组、端口所属的隔离组），和vlan配置（端口允许通过的vlan、端口本征vlan、vlan是否携带标签）

     即链路聚合大致过程为
     ①将物理端口捆绑成为聚合组，此时物理端口变为这个聚合组的成员端口
     ②从成员端口中选举出参考端口
     ③确定端口状态，只有操作Key和属性类配置与参考端口一致的成员端口才能被选中

- <b><p style="font-size:17px">三、聚合模式</p></b>
 1、静态聚合及过程
   静态聚合模式下，一旦配置好后，端口的转发流量的状态就不会收到网络环境的影响，优势是比较稳定，静态聚合过程如下：

     ①选择参考端口

         选举规则：

        Ⅰ、根据端口的高端口优先级>全双工/高速率>全双工/低速率>半双工/高速率>半双工/低速率的优先次序，选择优先次序最高，且属性类配置与对应聚合接口相同的端口

        Ⅱ、若此时优先次序相同，则选择原先的选中端口为参考接口

        Ⅲ、若此时所有端口都为选中端口，则选择其中端口号最小的为参考端口（端口号由端口优先级+端口编号组成）                 

     ②确定成员端口状态

            确定流程：

            硬件满足链路聚合要求 --> 端口处于up状态 --> 操作Key和属性类配置与参考端口一致 --> 聚合端口数量未超过上限 --> 该端口成为选中端口

 2、动态聚合及过程      
   动态聚合模式时根据LACP（Link Aggregation Control Protocol，链路聚合控制协议）实现的，处于动态聚合组内的成员端口可以收发LACP PDU，即链路聚合控制协议数据单元，通过LACP PDU可以交互消息，实现链路聚合两端各自选择的选中端口达成一致，优势是能根据对端调整端口状态，比较灵活。动态聚合过程如下

     ①选择参考端口

         选举规则：

         Ⅰ、先比较链路聚合两端设备ID，选择出较小的一端（设备ID为LACP优先级+系统MAC地址）

         Ⅱ、从这一端设备上，选择出端口ID较小的成员端口，该端口为参考端口                

     ②确定成员端口状态

确定流程：

硬件满足链路聚合要求 --> 端口处于up状态 --> 操作Key和属性类配置与参考端口一致 --> 对端端口的操作Key和属性类配置与参考端口一致 --> 聚合端口数量未超过上限 --> 该端口成为选中端口

- <b><p style="font-size:17px">四、注意事项</p></b>
1、聚合链路两端模式需要一致</p>
2、静态聚合需要保证的两端选举的选中端口一致</p>
3、二层和三层聚合组都有分为静态聚合和动态聚合</p>
4、聚合接口删除后，聚合组自动删除，且成员端口全都离开聚合组</p>
5、在聚合接口上配置属性，会被同步到成员端口，且聚合口删除后，配置仍然保留</p>
- <b><p style="font-size:17px">五、接口特性</p></b>
1、聚合接口的速率等于所有选中端口的速率之和</p>
2、聚合接口的双工模式则与选中端口的双工模式相同</p>
</span>

- <b><p style="font-size:17px">配置命令：</p></b>
 - - <p style="font-size:15px">二层聚合</p>

	     system-view					//进入配置模式
	     int Bridge-Aggregation 1			//创建二层聚合组
	     quit							//退出聚合组
	     int range 端口A to 端口B			//进入聚合组物理端口
	     port link-aggregation group 1		//分配聚合组
	     int Bridge-Aggregation 1			//进入二层聚合组
	     port link-type trunk				//聚合端口模式配置为trunk
	     port trunk permit  vlan all			//透传所有VLAN
	     undo port trunk permit vlan 1		//不允许VLAN_1通过
	     link-aggregation mode dynamic		//配置动态聚合LACP
	     quit							//退出聚合组		
	     save							//保存配置

 - - <p style="font-size:15px">三层聚合</p>

		 int Route-Aggregation 2			//创建三层聚合组
		 ip add X.X.X.X X.X.X.X			//配置聚合组IP
		 int range 端口A to 端口B			//进入聚合组物理端口
		 port link-mode route			//开启三层功能
         port link-aggregation group 2		//分配聚合组
		 link-aggregation  mode dynamic	//配置动态聚合LACP
		 负载均衡配置 -- 根据以下一种或几种组合分流，属于同一种数据流的报文从同一条链路上通过
    		link-aggregation load-sharing mode ?	
  			destination-ip   Destination IP address		//基于目的IP进行负载分担
  			destination-mac  Destination MAC address	//基于目的mac进行负载分担
  			source-ip        Source IP address         		//基于源IP进行负载分担
 			 source-mac       Source MAC address		//基于源mac进行负载分担
